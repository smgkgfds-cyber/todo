# Список задач (React + TypeScript)

Простое тестовое задание: список задач на Vite, React и TypeScript.

## Возможности

- добавление задачи через поле ввода и кнопку;
- переключение статуса «выполнена / не выполнена»;
- удаление задачи;
- фильтры: все, активные, выполненные;
- сохранение списка в `localStorage`;
- нельзя добавить пустую задачу или задачу из одних пробелов;
- выполненные задачи визуально отличаются от активных.

## Запуск

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Время выполнения

Ориентировочно 45 минут.
